🩺 Diabetes Prediction App

A machine learning–powered web application that predicts the likelihood of diabetes based on user health metrics. Built to help raise awareness and assist in early risk assessment.

🚀 Features

Input health details (e.g., age, BMI, glucose level, blood pressure).

Predicts diabetes risk using a trained ML model.

Clean and simple user interface.

Fast predictions with real-time feedback.

Can be deployed locally or on cloud platforms (Streamlit, Flask, FastAPI, etc.).

⚙️ Tech Stack

Frontend: Streamlit

Backend: Python

Machine Learning: scikit-learn, pandas, numpy

Model: Trained on the PIMA Diabetes Dataset (or your custom dataset)
